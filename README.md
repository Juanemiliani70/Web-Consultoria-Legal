# Parcial 2 - TP4 - Asesoría Legal Global

Laboratorio de Programación 3 - ISSD

Sitio web en ASP.NET Web Forms (.NET Framework 4.8) para una empresa de consultoría legal.

## Funcionalidades
- Master Page con navbar y footer en todas las páginas
- Registro de usuarios con validaciones (campos obligatorios, formato de correo, edad mayor de 15, coincidencia de contraseñas)
- Usuario guardado en sesión y contraseña en cookie
- Login con redirección al espacio personal
- Gestión de documentos: subida con validación de tipo y tamaño (máx. 5 MB), lista y descarga
- Diseño responsivo con CSS e imágenes de la empresa

## Cómo ejecutarlo
1. Abrir la solución en Visual Studio.
2. Presionar F5.
3. Registrarse, iniciar sesión y subir documentos. No usa base de datos.
